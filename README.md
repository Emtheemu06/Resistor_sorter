# Resistor_sorter
Idea hit me midday that I could make something to organize resistors for me so I don't have to sort them.
Currently just enter the colors of the resistor and it will calcalute the value. 
Colors need to be entered in order or it will not work and need to be separated by a space.
Hoping to make code for a camera that will replace entering each resitor by color on the users end but is a current work in progress.
